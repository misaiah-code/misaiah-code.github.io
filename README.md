## Upload the site to GitHub

1. Create a new GitHub repository. A name such as `CS499-ePortfolio` is fine.
2. On the repository page, choose **Add file → Upload files**.
3. Drag the **contents of this folder** into the upload area. `index.html` must be in the repository root.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose `main` and `/(root)`, then save.
8. Wait for GitHub Pages to publish the site and open the URL shown in the Pages settings.
